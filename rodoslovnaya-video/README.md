# Родословная Руты — видео (Remotion)

Вертикальное видео 1080×1920, 30 fps, 50 с: карта рода растёт снизу вверх,
от Руты и Милы до девятого поколения.

## Команды

```bash
npm i
npm run dev            # Remotion Studio, предпросмотр
npx remotion render    # → out/rodoslovnaya.mp4
```

## Что где лежит

- `src/data/family.json` — данные рода (не редактируются кодом).
- `src/data/people.ts` — загрузка данных, прямые предки, формат дат.
  Яков Шевченко (первый муж Ефимии, брак 1899) взят из раскадровки —
  в `family.json` его нет.
- `src/data/layout.ts` — раскладка: `y` по `gen`, `x` по ветвям
  (литовская слева, черкасская справа).
- `src/texts.ts` — **весь текст на экране** и длительности сцен в секундах.
  Под озвучку меняйте `durationSec`: камера и появление карточек
  пересчитаются от начала каждой сцены.
- `src/timeline.ts` — когда появляются карточки и линии, ключи камеры.
- `src/components/` — `PersonCard`, `Link`, `Scene`, `FamilyMap`.
- `public/fonts/` — Playfair Display (OFL), чтобы рендер не зависел от сети.

## Музыка

Положите файл в `public/music.mp3` — он подхватится автоматически
(громкость 0.35, зацикливается). Без файла видео рендерится без звука.
