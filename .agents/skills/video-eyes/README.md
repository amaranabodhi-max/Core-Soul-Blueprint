# video-eyes — научи Claude смотреть видео

Скилл для Claude Code / Claude Cowork: разбор видео (YouTube, Reels, TikTok,
Shorts) кадр за кадром с синхронизацией картинки и речи. Заточен под
русскоязычный контент.

Что умеет:
- скачивает видео по ссылке
- расшифровывает речь с таймкодами (русский — из коробки)
- для YouTube берёт готовые субтитры — быстрее и точнее
- режет видео на кадры умно: хук покадрово, остальное — по сменам сцен
- выдаёт разбор: хук, сцены, структура, механика удержания

Всё локально и бесплатно. Платишь только за токены Claude.

## Установка за 5 минут

### 1. Поставь три программы

**macOS** (нужен [Homebrew](https://brew.sh)):
```
brew install yt-dlp ffmpeg whisper-cpp
```

**Windows** (в PowerShell, нужен winget — есть в Windows 10/11):
```
winget install yt-dlp.yt-dlp Gyan.FFmpeg
```

Для whisper на Windows: скачай whisper.cpp с
https://github.com/ggml-org/whisper.cpp/releases (файл с `-bin-x64` в названии),
распакуй и добавь папку в PATH. Либо попроси Claude Code сделать это за тебя —
он умеет.

**Linux:**
```
sudo apt install ffmpeg && pip install yt-dlp
# whisper.cpp — собрать из исходников или взять из релизов на GitHub
```

### 2. Скачай модель для русского языка

```
mkdir -p ~/.claude/models
curl -L -o ~/.claude/models/ggml-small.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin
```

Это ~470 МБ, качается один раз. Важно: именно `small`, а не `base.en` —
`base.en` понимает только английский.

Слабый компьютер? Возьми `ggml-base.bin` (~150 МБ) — чуть хуже качество,
зато быстрее.

### 3. Положи скилл на место

Скопируй папку `video-eyes` (вот эту, со SKILL.md внутри) в:
```
~/.claude/skills/video-eyes/
```

То есть должно получиться: `~/.claude/skills/video-eyes/SKILL.md`

На Windows: `C:\Users\<имя>\.claude\skills\video-eyes\SKILL.md`

### 4. Проверь

Открой Claude Code и напиши:
```
Разбери этот рилс: <ссылка>
```

Claude сам подхватит скилл, скачает видео, нарежет кадры, расшифрует речь
и выдаст разбор.

## Чем отличается от оригинального claude-watch

Оригинал: https://gist.github.com/conradcaffier03/ef914685fc9d7da91b6591947fa1ddb2

1. **Русский язык.** В оригинале модель `base.en` — English only. Здесь
   мультиязычная `small` с автоопределением языка.
2. **Субтитры YouTube.** Если у ролика есть субтитры, берём их напрямую
   через yt-dlp — без прогона через whisper. Быстрее и точнее.
3. **Детект смены сцен.** Оригинал берёт 1 кадр каждые 3,5 секунды вслепую.
   Здесь кадр берётся, когда картинка реально поменялась — меньше мусорных
   кадров, не пропускаются быстрые склейки.
4. **Таймкоды везде.** Транскрипция в srt + секунда каждого кадра. Claude
   точно знает, что говорилось в момент каждого кадра — сшивка «речь ↔
   картинка» не на глазок.
5. **Читаемый текст на экране.** Кадры тела 640px вместо 360px — плашки
   и титры не превращаются в кашу.

## Как передать скилл другим

Скилл — это просто папка с двумя markdown-файлами. Варианты:
- **Ссылкой:** выложи SKILL.md и README.md в свой gist на
  https://gist.github.com — получишь постоянную ссылку, как у оригинала.
- **Файлом:** кинь zip в Telegram/куда угодно. Установка — пункт 3 выше.
- **Репозиторием:** заведи репо на GitHub, если хочешь принимать правки.
