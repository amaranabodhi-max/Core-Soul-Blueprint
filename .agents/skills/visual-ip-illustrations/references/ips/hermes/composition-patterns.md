## Composition Families

Use one composition family per image.

### Workflow

Hermes Agent moves a concept through 3-5 sparse steps, such as input, check, route, and output. Use simple stations, tokens, gates, or trays.

### System Local View

Hermes Agent inspects one small part of a system. Use a magnified node, small machine, exposed hinge, source card, or decision switch.

### Before/After

Hermes Agent actively changes one state into another. Keep two clear zones with a simple action bridge between them.

### Character State

Hermes Agent's posture and action express the cognitive state: focused, verifying, shielding, comparing, repairing, routing, or pruning.

### Concept Metaphor

Hermes Agent turns an abstract idea into a physical metaphor: bridge, knot, lens, shelf, signal, map, switch, lock, relay, compass, or small machine.

### Method Layers

Hermes Agent handles stacked layers with one action per layer. Use 3-4 layers with sparse labels and a visible route through them.

### Map Route

Hermes Agent guides packets, notes, or decisions across a map with branches, checkpoints, and a destination.

### Mini Comic

Hermes Agent performs 2-3 tiny panels of one idea changing over time. Keep panels sparse, border-light, and action-driven.

- Sorting: Hermes Agent sorts fragments, claims, labels, or packets into simple groups.
- Routing: Hermes Agent directs a token through decision gates or a route map.
- Verifying: Hermes Agent checks a source card, license tag, or identity marker.
- Repairing: Hermes Agent fixes a broken bridge, tangled wire, or leaking route.
- Shielding: Hermes Agent protects source context from noisy claims.
- Tuning: Hermes Agent adjusts a signal, antenna, dial, or alignment line.
- Trimming: Hermes Agent removes excessive labels or clutter.
- Bridging: Hermes Agent connects two parts of an idea with a physical bridge.
