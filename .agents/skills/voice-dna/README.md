# voice-dna

Skill для Claude Code / Claude, который собирает **живой голос автора** в один файл `voice.md` за один заход.

Ты кидаешь 5–15 своих текстов (посты, рассылки, расшифровки голосовых, длинные сообщения) — скилл молча разбирает их по 6 осям стиля, показывает короткий отчёт-перебивку и предлагает развилку: собрать файл сразу или докрутить голос через любимых авторов и личные антипатии.

На выходе — один файл `voice.md` (~120–150 строк): связный портрет голоса с цитатами, аудитория, стоп-фразы, эталоны с разбором «работает потому что» и самопроверка под конкретного автора.

## Принцип

- **Один заход, один файл, без раздувания.**
- Минимальный путь — 2 такта (свои тексты → файл).
- Полный путь — 5 тактов (свои → разбор → чужие эталоны → антипатии → файл). Все шаги после первого опциональны.
- Каждое наблюдение подтверждается дословной цитатой. Нет цитаты — нет наблюдения.

## Когда использовать

- Первый запуск копирайтера/контент-агента — голоса ещё нет.
- Перед первым продающим текстом, если `voice.md` пустой или отсутствует.
- «Давай переберём голос», «обнови мой стиль».

## Когда НЕ использовать

- Нужен голос **бренда** (компании, продукта) — это отдельный скилл `/brand-voice`.
- Нужно просто написать текст — это к копирайтеру.
- У тебя меньше 5 текстов и нет возможности добавить — лучше отказать, чем собрать пустышку.

## Установка

Скопируй `SKILL.md` в папку скиллов Claude Code, например:

```
~/.claude/skills/voice-dna/SKILL.md
```

Затем вызывай по триггерам: `voice dna`, `/voice-dna`, «собери мой голос», «распакуй стиль», «обнови голос».
